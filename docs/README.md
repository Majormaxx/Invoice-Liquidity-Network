# docs/ — Legacy Nextra 2 source (migration in progress)

> **This directory is NOT the production documentation site.**
>
> The live site at **docs.iln.finance** is built
> from [`packages/docs/`](../packages/docs) (Nextra 3, Next.js 15 App Router).
> `docs-deploy.yml` exclusively builds and publishes `packages/docs/`.
>
> The content files (`.md`) in this directory are the source of truth for
> documentation prose while migration is in progress. New pages should be
> written here **and** ported to `packages/docs/content/` as part of the
> migration tracked in [`DOCS_SETUP.md`](./DOCS_SETUP.md).

---

## What lives here

| Path | Purpose |
|---|---|
| `*.md` | Protocol documentation source files |
| `pages/` | Nextra 2 Pages Router entry point (non-deployed) |
| `components/` | AlgoliaSearch component (Nextra 2, non-deployed) |
| `theme.config.jsx` | Nextra 2 theme config (non-deployed) |
| `changelog.md` | Auto-generated by `docs-changelog.yml` on every push to `main` |
| `DOCS_SETUP.md` | Migration checklist and dev setup guide |

## Why two docs directories?

`packages/docs/` (`@invoice-liquidity/docs-next`) was created to migrate the
docs site from Nextra 2 (Pages Router) to Nextra 3 (App Router) with
Tailwind, Next.js 15, and React 19. During migration the original `docs/`
directory is kept as the authoritative content source. Once all content is
ported and the new site is verified in production, `docs/` will be reduced
to a content-only directory (no Next.js app files) and this notice will be
removed.

See [`DOCS_SETUP.md`](./DOCS_SETUP.md) for the full migration checklist and
remaining work.

## Local development (legacy site, not deployed)

```bash
# From repo root
pnpm --filter @invoice-liquidity/docs dev
# Site runs at http://localhost:3000 (Nextra 2)
```

## Local development (canonical deployed site)

```bash
# From repo root
pnpm --filter @invoice-liquidity/docs-next dev
# Site runs at http://localhost:3000 (Nextra 3 / App Router)
```
